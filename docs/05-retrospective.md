# 复盘

| 项目 | 内容 |
|---|---|
| 主要取舍 | JSON 单文件库 + 规则版 `MockPolicy`，保证「零依赖可跑、结论可复现」；MySQL 设计与真实模型路径以「可替换实现 + 文档」保留，而不是假装已经跑通 |
| 已完成 | ReAct 循环（agent⇄act）+ 限步；R001–R009 审核规则（含内容指纹去重）；幂等草稿保存；单素材单排期守卫；硬/软冲突分流；提醒降级；DeepSeek 客户端（重试/超时/错误码）并**用真实 key 跑通 3 条路径**；本地 Web 界面（选素材/时段、决策时间线、草稿箱、素材详情、素材增删改查）；`@tool` 装饰器 + 包扫描的工具发现；155 个测试；11 组示例输出；6 条执行路径记录；六篇文档 |
| 踩过的坑 | ① 幂等键写在保存层，但冲突判断更早把请求推到了别的时段，导致重复提交真的产生两份草稿；② 唯一索引的 NULL 语义没对齐 MySQL；③ 提醒失败一度把整单排期带崩；④ Windows 锁文件 delete-pending 抛 `PermissionError`，并发测试约 5% 概率失败；⑤ 第一版 ReAct 把 `ToolContext` 每轮重建，导致「补查」永远读到同一份数据，等于没补；⑥ 只读 `os.environ` 不读 `.env`，用户配了 key 仍报没有 key；⑦ 工具名带点号被 DeepSeek 用 400 拒绝；⑧ 真实模型会不落草稿直接 `finish(needs_confirmation)`，凭空"完成"；⑨ 唯一键只挡「同素材同时段」，换个时段还能再排一条，同一素材可能占两个档；⑩ 完全没有内容重复检测，同一文件换个 ID 就能再发一次 |
| 已知不足 | 真实模型只跑了 3 条路径、单模型单次，样本不足以下质量结论；无批量与并发压测；时段容量固定为 1；无鉴权与服务化 |
| 下一步 | ① 接真实模型做同一素材的 A/B（规则 vs 模型，看动作序列与结论差异）；② 迁移 MySQL，用 `SELECT … FOR UPDATE` 替换文件锁；③ 批量入口 + 失败隔离；④ 加 `interrupt` 做人工确认节点；⑤ 并行 tool_calls |
| 下一轮验证 | 同素材下对比两种策略的动作序列与 token 成本；重复提交与并发抢时段的失败率；从请求到草稿的端到端耗时 |

## 实际用时

按墙钟记录（AI 辅助实现 + 人工评审各轮），单轮为一次交互：

| 阶段 | 内容 | 用时 |
|---|---|---|
| 1 | 读懂题目、补全设计稿（`题目.md`） | ~15 min |
| 2 | 搭骨架：存储/规则/工具/图/CLI，跑通六类验收 | ~50 min |
| 3 | 测试（59→60）、边界修复、示例与文档 | ~30 min |
| 4 | 并发 Bug（Windows 锁）+ BOM 修复 | ~20 min |
| 5 | **ReAct 改造**：策略层、动作注册表、限步、决策日志 | ~45 min |
| 6 | 执行路径记录、文档同步 | ~20 min |
| 7 | **DeepSeek 客户端**：真实 HTTP、重试矩阵、错误码、冒烟脚本、20 个单测 | ~35 min |
| 8 | **真实联调**：`.env` 加载、工具名合规、落草稿兜底、3 条路径记录 | ~40 min |
| 9 | **Web 界面**：HTTP API、单页前端、确认/重置、13 个测试 | ~45 min |
| 合计 | | **≈ 4 小时** |

对照考核建议的 3 小时：核心链路、ReAct 循环、真实模型接入与联调、界面、测试与记录都在内；线上部署与多 Agent 未做（考核也列为非必需）。

## 没做完的部分（明确列出，不混进"已完成"）

| 项 | 状态 | 影响 |
|---|---|---|
| 真实模型覆盖度 | 只用 `deepseek-flash` 跑过 3 条路径（各 1 次） | 不足以评价决策稳定性；换素材/换模型未测 |
| 多素材批量 | 未实现，只有单素材入口 | 只能一条一条跑 |
| 时段容量 > 1 | 未实现（固定 1 条/档） | 同一档位不能排多条素材 |
| 界面鉴权 | 无，只监听 127.0.0.1 | 仅本机演示；不要暴露公网 |
| 鉴权 / 服务化 | 未实现（CLI 单机） | 仅本地可用 |
| 真实发布 | 明确不做 | `PUBLISHED` / `release_date` 恒不写 |

不因未实现无必要的复杂架构扣分；不能把「计划做」记为「已实现」。
本仓库当前是「链路完整、判定确定、决策循环真实、模型缺席」的状态——这是 mock 模式的定义，不是遗漏。
